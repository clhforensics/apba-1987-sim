# APBA Pro Basketball 1987 Simulator

A Python simulation of the 1986-87 NBA season based on APBA Pro Basketball board game mechanics.

## Overview

This project recreates the 1986-87 NBA season using real historical data and APBA-style statistical play. Companion project to the [APBA 1989 NBA Simulator](https://github.com/clhforensics/apba-1989-sim).

## Requirements

- Python 3
- Historical stats data (`stats.csv`)

## Related Projects

- [APBA 1989 NBA Simulator](https://github.com/clhforensics/apba-1989-sim) — Full-featured simulation with play-by-play, coaching strategies, and momentum physics
